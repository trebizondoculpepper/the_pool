# Introduction letter: the Institute of Swimming Pool Engineers

To Luke at the Institute of Swimming Pool Engineers (ISPE). The owner's version, 2026-11-03, with its typos corrected.

---

Dear Luke,

I'm a software developer working on _The Pool_, a game that simulates the engineering and operation of a large leisure centre's swimming pools: not the pool hall, but the plant rooms and engineering behind it.

The game plays in a web browser (for example Chrome), provided you have a fast enough computer. You can play it free here:

https://trebizondoculpepper.github.io/the_pool/

This is still an early build of the game and there is much to do. You will notice that the brands are all fictional, but except in a few places the game sticks closely to real-world hydrodynamics, thermodynamics and chemistry.

Pretty much everything in the game is a working part of the simulation. Filters can get dirty. Pumps can trip out. pH can become unbalanced… and many other disasters. The idea of the game was to create a simulation that forces the player to problem-solve and reason about a colossal real-world system. I also wanted to create a system that, whilst complex and initially baffling, has a real-world logic.

I'd be very happy to give you a short demonstration, online or in person, and to talk about whether there might be some mutual interest.

Kind regards,
