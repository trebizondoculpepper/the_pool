# 2026-11-07 · Phone controls while moving

Issue #76 implements the owner's revised phone input rule in the shared controls layer. The old `inputHeld` gate combined world use with walking and looking; a separate motion gate now leaves WASD, mouse look, touch sticks and gamepad sticks active while the handset is raised, while world use stays blocked. Arrow keys and Enter replace W/A/S/D/E for phone navigation. The handset is registered with the shared click resolver, with its own foreground scene root so visually foreground phone keys cannot be hidden by nearby world geometry; mouse and touch use the same resolution and action. The model-local display and button coordinates follow its rendered pose, so the Messages icon and inbox rows can be tapped on the phone. The six separate phone buttons remain as a fallback above the left movement stick. A carried object remains concealed until the phone is lowered. Browser confirmation is still needed because the computer-use browser was unavailable during this session; typecheck and the focused menu tests passed.
