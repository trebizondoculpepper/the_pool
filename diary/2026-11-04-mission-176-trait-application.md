# Mission 176: applying kind traits

I took over stage 2 after Nicole's handover. The owner-approved plan mapped 107 kinds to traits; I applied every row through `npm run -s audit -- set`, leaving the kind files to the command. The existing floppy disk kind was already classified. I reclassified the engineers' desk and storage cupboard from decorative to non-plant, which required permanent installation IDs for the desk and two cupboards so the equipment catalogue would continue to load.

The first full test run found stale audit expectations and missing model bindings for the newly non-decorative office furniture. I added the desk and cupboards to the office schematic, gave them permanent tags and graph tiers, and updated the affected tests. The final full `npm test` passed: 701 files and 5,880 tests, with 74 expected failures and 12 skipped files. Typecheck, lint, format check, build and `audit check` passed too. `unclassified` still found 21 kinds without a support trait, chiefly in-line fittings and held objects. The current support facet only has floor-standing, wall-mounted and ceiling-mounted, so I asked the owner how those kinds should be represented before enabling the final enforcement rule.
