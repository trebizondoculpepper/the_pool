# Release v0.13.0

The owner requested a release. I completed the Episode 1 source screenshot and description link that were still in the working tree, ran the full project checks, and cut v0.13.0 with `npm run release`. The release commit is `8cd32d3c` and the annotated tag was pushed with `main`.

The tag workflow published the GitHub release but itch.io returned `invalid target (bad user)` for `salimfadhley/the-pool:html5`. The game's public itch.io URL redirects to `trebizondoculpepper.itch.io/the-pool`; the earlier v0.12.0 upload had worked with the old target. I changed the workflow's butler target to `trebizondoculpepper/the-pool:html5` on `main` and used the documented workflow dispatch to publish the existing tag again, without changing the tag.
